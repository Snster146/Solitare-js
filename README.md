# 🃏 Solitare-js  
A fun, pixel/retro inspired web-based implementation of the classic klondike solitare game built with JavaScript.  
## Features
* ♠️ Classic Klondika Solitare gameplay
* ♣️ Fully playbale in the browser
* ♥️ Pixelated / retro-inspired
* ♦️ Responsive design for different screen sizes
* ♠️ How to play and Rules sections 
### Demo
Play the game here:  
👉[https://snster146.github.io/Solitare-js/](https://snster146.github.io/Solitare-js/)
### Project Goal
The goal of this project is to take a classic card game and reimagine it as a fun, pixel art/retro experience.
